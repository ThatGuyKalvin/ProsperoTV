## New since 01.000.060

### Watching

- **A new playback menu.** Options opens one **Playback** sheet at the side with Sound, Subtitles, Picture and Video. Each row opens a list with the value in use ticked; it replaces the five L1/R1 tabs.
- **Picture modes you can see.** Each mode has a small preview of the shape it gives, and Fit names the video's own shape ("Fit · 16:9"), so a wrongly shaped stream is easy to correct. The bars around a reshaped picture stay black.
- **Sharper controls.** The playback controls, the live channel list and the menu are drawn at the screen's resolution whatever the stream's, in the same look as the rest of the interface. The controls show the title with its state (Paused, Buffering, Live, Replay or the speed), the programme now and next, and a timeline.
- **The statistics line hides by itself.** The codec, resolution and frame rate line disappears five seconds after the first picture. Touchpad + R1 shows it again for five seconds.

### Fixes

- **No black second at launch.** On consoles set to apply VRR to unsupported games, the screen went black for a second or two when the app opened and again when it closed.
- **Providers that send oversized data.** One channel with a whole picture for a logo, or one show with a very long cast list, made the whole list fail ("provider returned malformed Xtream data", "The provider's on-demand list could not be downloaded"). Such an entry is now kept without the oversized part.

### Maintenance

- Built on ps5-opengl SDK 1.0.2 and the current interface kit.
- The filesystem access helper is updated to the revision ProsperoEden and ProsperoStore use.

## Validation notes

Host tests cover the playback menu, the channel list, the controls, the statistics line's timing and the provider data fixes. On a console with system software 12.70, a build of this version launched without a video mode change, opened every tab, played a 4K film and a live channel for 150 seconds each with the controls and the menu used during playback, changed channel five times in ten seconds, and closed cleanly.

## Installing by hand

- `PPSA99003.zip`: extract it and upload the complete `PPSA99003` folder to `/data/homebrew`, replacing the old one after closing the app. Keep your existing data under `/data/prosperotv`.
- `SHA256SUMS`: the checksum of the download.
- Coming from 01.000.015 or older: close ProsperoTV, delete `PPSA99003.ffpfsc` from `/data/homebrew` if you used the image, then upload the folder and restart ShadowMountPlus or the console.

Release files are built by this repository's GitHub Actions from the version tag on the release commit from `main`.
