## New since 01.000.100

### Fixes

- **10-bit video at unusual widths.** Some 10-bit HEVC videos at widths other than the usual 1920 or 3840, such as 2592×1080, failed at the first picture with "The PS5 video backend failed (native error 0xFFFFFFFF)". They now play. A video whose rows the decoder pads to a width the graphics chip does not expect is repacked before it is shown.

## Validation notes

Checked on a PS5 with a 2592×1080 HEVC Main10 video with 5.1 sound, which failed at the first picture before and now plays with picture and sound in step. Host tests of the shared playback code pass.

## Installing by hand

- `PPSA99003.zip`: extract it and upload the complete `PPSA99003` folder to `/data/homebrew`, replacing the old one after closing the app. Keep your existing data under `/data/prosperotv`.
- `SHA256SUMS`: the checksum of the download.
- Coming from 01.000.015 or older: close ProsperoTV, delete `PPSA99003.ffpfsc` from `/data/homebrew` if you used the image, then upload the folder and restart ShadowMountPlus or the console.

Release files are built by this repository's GitHub Actions from the version tag on the release commit from `main`.
