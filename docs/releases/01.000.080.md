## A new home

BlackBearReloaded, who created ProsperoTV and wrote most of it, has handed the project to ThatGuyKalvin. It now lives at https://github.com/ThatGuyKalvin/ProsperoTV; old links redirect. The About tab and the README say who made it, and no licence or copyright notice changes.

- **Updates in the app.** The catalog the app checks moved from homebrew.page to prosperostore.net. This is the first version that asks the new address, so from here on in-app updates work again. A copy of 01.000.070 or older asks the old address, which now redirects, and never sees this release: install this one by hand, as below.
- **Checking a download.** `gh attestation verify PPSA99003.zip -R ThatGuyKalvin/ProsperoTV` verifies the release files from this version on.

## New since 01.000.070

### Watching

- **Seeking stays in the video.** A seek in a film, an episode or a replay moves within the open video instead of closing it and opening it again at the target. The network, the decoder and the presenter stay up, the tuning screen no longer appears, and the last picture stays on screen until the new one is ready. On a console the picture at the target arrives in about 1.5 to 3 s where it took about 8.6 s before, and the sound settles to within about a hundredth of a second of it.
- **HDR colours as they should be.** HDR10 and HLG pictures showed blue as red. The colour shader packed red where the console's HDR scanout format expects blue; it now exports blue, green, red in every mode, the same way the SDR modes already did. 1080p and SDR pictures are unchanged.
- **A Stats line switch.** Settings → Troubleshooting has a **Stats line** switch that keeps the codec and performance line on screen for the whole playback. Off, the line still shows for five seconds at the start and on Touchpad + R1.

### On Demand

- **Carry on with a show.** A show's episode list opens with a **Continue** row above its seasons: the episode started last, at the position it was left at, with the minutes watched beside it. A finished episode hands over to the next one. A hidden category, a hidden channel or a parental rule takes the row away, the same as on the home screen.
- **Film details that arrive.** A film's details often said the provider gave no synopsis when it had one: a request made while the daily list update or the guide download was running was dropped. It now waits its turn and goes ahead of a pending list update, and the panel says "Loading title details" meanwhile. Playlists served by an Xtream server get details for their films too.
- **Long lists.** A list of more than 100,000 titles used to be thrown away as too large, and one title with an oversized name failed the whole list. The app now holds up to 250,000 titles, keeps the first ones of a longer list and says so in the status line, and leaves out an entry it cannot read instead of the list.
- **A quicker menu.** The On Demand menu counts its films and shows from a summary saved beside each list instead of reading both lists again, every saved list is read off the interface thread, and the list left for the other kind comes straight back. Opening Movies no longer freezes the interface, and returning to the menu is immediate.

### Maintenance

- The app's memory heap is 1 GiB (it was 512 MiB), so a provider's whole film list fits beside the interface while a refresh holds the old and the new one.
- Diagnostic log lines for the on-demand loader: what a download is for, how each list ended, and the heap in use.
- The update check asks prosperostore.net, the catalog's new address (see A new home).
- The owned-root helper is fetched from a mirror of the fork it was pinned to; the pinned commit is unchanged.

## Validation notes

Host tests cover the seek within an open video, the HDR shader's export order in every mode, the Stats line switch, the Continue row, the details queue, the long-list limits and the summary-based counts. On a console with system software 12.70, a build of this version was installed and run through its tabs; the seek, the long-list and the menu timings above were measured there.

## Installing by hand

- `PPSA99003.zip`: extract it and upload the complete `PPSA99003` folder to `/data/homebrew`, replacing the old one after closing the app. Keep your existing data under `/data/prosperotv`.
- `SHA256SUMS`: the checksum of the download.
- Coming from 01.000.015 or older: close ProsperoTV, delete `PPSA99003.ffpfsc` from `/data/homebrew` if you used the image, then upload the folder and restart ShadowMountPlus or the console.

Release files are built by this repository's GitHub Actions from the version tag on the release commit from `main`.
